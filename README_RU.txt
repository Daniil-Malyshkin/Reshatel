РЕШАТЕЛЬ 1.0
Проект индивидуальной разработки: адаптивный математический веб-сервис для компьютера, Android и iPhone.

ОПИСАНИЕ ПРОЕКТА
«Решатель» предназначен для ввода математических выражений, уравнений, неравенств и систем с получением ответа и пошагового объяснения. В проекте предусмотрена поддержка тригонометрических уравнений (sin, cos, tg/tan, ctg), включая запись sin²(x), а также общие решения с периодом. Углы задаются в радианах.

Планируемый режим использования — установка веб-приложения на главный экран смартфона или компьютера и выполнение вычислений непосредственно в браузере. Для офлайн-работы необходимо предварительно загрузить вычислительное ядро и ресурсы при подключении к интернету.

ВАЖНО О СТАТУСЕ
Проверено математическое ядро на наборе типовых примеров в локальной среде Python/SymPy. Это не заменяет проверку интерфейса в реальных браузерах и на телефонах. Перед публичной демонстрацией необходимо проверить полный сценарий в Chrome, Safari и на Android/iPhone, включая перезапуск без интернета. До такой проверки нельзя утверждать, что все функции уже безошибочно работают на каждой платформе.

ЧТО ЕСТЬ В ПРОЕКТЕ
- Адаптивный интерфейс для широкого экрана и телефона.
- Математическое ядро на Python, SymPy и Pyodide (Python в браузере).
- Пошаговые решения и дополнительное пояснение выбранного шага.
- PWA-манифест, иконки для браузеров и экранов установки.
- Кнопка установки: автоматическое предложение там, где браузер его поддерживает, и краткая инструкция для iPhone/iPad и Android.
- Service Worker: локальные файлы приложения и загруженные файлы Pyodide/SymPy сохраняются в кэш браузера.
- Нормализация распространённой вставки из LaTeX/Word/PDF: дроби, корни, π, знаки сравнения и умножения.
- Копирование ответа с запасным способом для браузеров без Clipboard API.
- Ограниченный набор глобальных объектов парсера: пользовательский ввод не получает доступ к стандартным функциям Python.

ЗАПУСК НА WINDOWS ДЛЯ ПРОВЕРКИ
1. Распакуй архив в отдельную папку.
2. Установи Python 3, если он ещё не установлен (он нужен только для локального веб-сервера).
3. Запусти start_windows.bat.
4. Откроется http://localhost:8000. Не закрывай окно сервера, пока пользуешься приложением.
5. При первом запуске подключись к интернету и дождись статуса «Вычислитель готов».
6. После успешной загрузки перезагрузи страницу один раз, пока интернет ещё включён.
7. Отключи интернет и перезагрузи страницу. Если вычислитель загружается и задача решается, офлайн-кэш на этом браузере работает.

УСТАНОВКА НА ANDROID
Для установки PWA нужен HTTPS-адрес (localhost годится только для локальной проверки на компьютере).
1. Размести содержимое папки на статическом HTTPS-хостинге.
2. Открой адрес в Chrome на телефоне.
3. Дождись статуса «Вычислитель готов», чтобы Pyodide и SymPy успели загрузиться и попасть в кэш.
4. Выбери «Установить приложение» или «Добавить на главный экран».
5. Запусти установленное приложение и проверь его в авиарежиме.

УСТАНОВКА НА IPHONE
1. Размести содержимое папки на HTTPS-хостинге.
2. Открой сайт в Safari.
3. Дождись статуса «Вычислитель готов» при подключённом интернете.
4. Нажми «Поделиться» и выбери «На экран Домой» / «Добавить на экран Домой».
5. Запусти приложение с экрана «Домой», дождись полной загрузки вычислителя и проверь работу без интернета.

ОФЛАЙН-РЕЖИМ: ВАЖНО
- Приложение не может впервые установиться и загрузить вычислитель без интернета.
- После первого онлайн-запуска Service Worker кэширует локальные файлы проекта и запрошенные файлы Pyodide/SymPy с CDN.
- После успешной загрузки вычислителя решение задач должно выполняться на устройстве без постоянного подключения к сети.
- Не очищай данные сайта/кэш браузера: при их удалении ресурсы придётся загрузить заново.
- Реальное поведение офлайн-кэша зависит от браузера, свободного места и настроек очистки данных. Поэтому после публикации обязательно проверь авиарежимом на каждом целевом устройстве.
- PWA — это устанавливаемая веб-версия, а не отдельный APK или приложение из App Store.

ПРИМЕРЫ, ПРОВЕРЕННЫЕ В МАТЕМАТИЧЕСКОМ ЯДРЕ
2x + 3 = 11                 -> x = 4
x^2 - 5x + 6 = 0            -> x₁ = 2; x₂ = 3
log_2(x) = 3                -> x = 8
x^2 - 4 >= 0                -> (-∞; -2] ∪ [2; ∞)
sin(x) = 0                  -> общее решение с периодом
2x + 3y = 6; x - y = 1      -> x = 9/5, y = 4/5

ОГРАНИЧЕНИЯ
- Приложение решает поддерживаемые типы математических выражений, уравнений, неравенств и систем, а не абсолютно любую задачу. Для дробно-рациональных выражений обязательно отдельно проверяй ОДЗ: при сокращении дробей ограничения знаменателя могут потеряться.
- Графики и распознавание задач по фотографии не реализованы: их не было в исходном Python-проекте.
- В этой среде выполнены локальные проверки математического ядра и файлов проекта. Полный запуск в реальных Chrome, Safari и Android/iPhone, включая установку и авиарежим, здесь не выполнялся. Эти проверки нужно провести после публикации по инструкциям выше.


ВИЗУАЛЬНЫЙ ВВОД МАТЕМАТИКИ

Поле задачи использует MathLive: дроби, степени, индексы и корни отображаются как математическая запись, а не как служебные символы. Клавиатура сохранена в тёмно-синем оформлении проекта и разделена на вкладки «Числа» и «Буквы». Во вкладке букв доступны латинские переменные в нижнем и верхнем регистре.

Для первого открытия визуального поля требуется загрузить MathLive с CDN; после загрузки Service Worker может кэшировать библиотеку для последующих открытий. Если библиотека недоступна, остаётся обычное текстовое поле ввода.

Вычислительное ядро поддерживает отдельные переменные латинского алфавита, в том числе системы с несколькими переменными. Буквы с разным регистром считаются разными переменными. Число e как переменная доступно обычной буквой e; число Эйлера можно записать как exp(1).

ЗАФИКСИРОВАННАЯ ВЕРСИЯ 1.0
- Ввод нормализует символы √, ≤, ≥, ≠, ×, ÷, π и десятичную запятую.
- Поддерживается распространённая LaTeX-запись дробей и корней: \frac{1}{2}x=3, \sqrt{9}+1.
- Нормализация выполняется до определения типа задачи, поэтому Unicode-неравенства распознаются как неравенства, а не как выражения.
- При копировании ответа используется Clipboard API, а при его недоступности — резервный способ через выделение текста.
- Проверены линейные и квадратные уравнения, системы, неравенства, логарифмы, тригонометрия, дроби и корни.


ФИКСАЦИЯ ВЕРСИИ
Эта сборка обозначена как версия 1.0. Не изменять файлы, функции и оформление этой версии без прямого разрешения пользователя.

ДОПОЛНИТЕЛЬНЫЕ ФУНКЦИИ СБОРКИ
- История последних 30 успешно решённых задач хранится локально в браузере на устройстве. Нажатие на задачу восстанавливает её во входном поле; историю можно очистить.
- Степени отображаются надстрочными символами (например, x² и x³) во входной записи, ответах, шагах решения и истории.
- Проверка собственного ответа сравнивает нормализованную запись с ответом программы; это не доказательство математической эквивалентности разных форм записи.


НОВЫЕ ВОЗМОЖНОСТИ СБОРКИ
- История последних 30 решённых задач хранится в браузере на этом компьютере.
- Нажатие на задачу в истории восстанавливает её в поле ввода.
- Степени отображаются надстрочными символами (например, x², x⁻³); вычислитель преобразует их во внутреннюю запись автоматически.
- После решения можно проверить собственный ответ. Проверка сравнивает нормализованную запись ответа, но не доказывает математическую эквивалентность разных форм записи.
- При запуске показывается заставка с логотипом; основное приложение открывается после подготовки вычислительного ядра. При ошибке загрузки можно повторить попытку или открыть интерфейс.
